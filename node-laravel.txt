| Laravel                                    | Node.js (Sequelize)                                                  |
| ------------------------------------------ | -------------------------------------------------------------------- |
| `return response()->json(Product::all());` | `const products = await Product.findAll();`<br>`res.json(products);` |
| `Product::create([...]);`                  | `const product = await Product.create({ name: req.body.name });`     |
| `$product = Product::find($id);`           | `const product = await Product.findByPk(req.params.id);`             |
| `$product->delete();`                      | `await product.destroy();`                                           |
| `$product->update([...]);`                 | `await product.update({ name: req.body.name });`                     |


  

| MySQL (Sequelize)   | MongoDB (Mongoose)                                |
| ------------------- | ------------------------------------------------- |
| `Task.findAll()`    | `Task.find()`                                     |
| `Task.findByPk(id)` | `Task.findById(id)`                               |
| `Task.create(data)` | `Task.create(data)`                               |
| `task.update(data)` | `Task.findByIdAndUpdate(id, data, { new: true })` |
| `task.destroy()`    | `Task.findByIdAndDelete(id)`                      |

| Operation           | MySQL (Sequelize)                                                                 | PostgreSQL (Sequelize)                                                            | MongoDB (Mongoose)                                              |

| Get All             | `Task.findAll()`                                                                  | `Task.findAll()`                                                                  | `Task.find()`                                                   |

| Create              | `Task.create(data)`                                                               | `Task.create(data)`                                                               | `Task.create(data)`                                             |
| Update by ID        | `task.update(data)`                                                               | `task.update(data)`                                                               | `Task.findByIdAndUpdate(id, data, { new: true })`               |
| Delete by ID        | `task.destroy()`                                                                  | `task.destroy()`                                                                  | `Task.findByIdAndDelete(id)`                                    |
| Find One            | `Task.findOne({ where: { title: "Test" } })`                                      | `Task.findOne({ where: { title: "Test" } })`                                      | `Task.findOne({ title: "Test" })`                               |
| Find with Condition | `Task.findAll({ where: { status: "pending" } })`                                  | `Task.findAll({ where: { status: "pending" } })`                                  | `Task.find({ status: "pending" })`                              |
| Count               | `Task.count()`                                                                    | `Task.count()`                                                                    | `Task.countDocuments()`                                         |
| Select Columns      | `Task.findAll({ attributes: ["title","status"] })`                                | `Task.findAll({ attributes: ["title","status"] })`                                | `Task.find({}, "title status")`                                 |

| Limit               | `Task.findAll({ limit: 5 })`                                                      | `Task.findAll({ limit: 5 })`                                                      | `Task.find().limit(5)`                                          |

| Equal               | `Task.findAll({ where: { status: "pending" } })`                                  | `Task.findAll({ where: { status: "pending" } })`                                  | `Task.find({ status: "pending" })`                              |

| Less Than           | `Task.findAll({ where: { id: { [Op.lt]: 5 } } })`                                 | `Task.findAll({ where: { id: { [Op.lt]: 5 } } })`                                 | `Task.find({ age: { $lt: 5 } })`                                |
| Between             | `Task.findAll({ where: { id: { [Op.between]: [1,10] } } })`                       | `Task.findAll({ where: { id: { [Op.between]: [1,10] } } })`                       | `Task.find({ age: { $gte: 1, $lte: 10 } })`                     |
